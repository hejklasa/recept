# Receptövning

Övningsprojekt enligt Figma-länken i [kursrepot för Test och kartläggning](https://github.com/Lexicon-Utbildning-Front-end-2026-2027/test-och-kartlaggning). En enkel, responsiv receptsida för pannkakor byggd med semantisk HTML och modern CSS.

## Innehåll

- Semantisk HTML (`article`, `header`, rubriknivåer, listor)
- Responsiv layout
- Tillgänglighet enligt WCAG (alt-texter, kontrast, `lang`-attribut)
